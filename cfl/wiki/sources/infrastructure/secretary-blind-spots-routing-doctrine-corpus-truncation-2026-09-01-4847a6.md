# Secretary trunk, 2026-09-01: routing doctrine, a self-caught procedural defect, and the resident's false finding traced to a stale export (4847a6)

## Summary

A 24-turn claude.ai Secretary-seat session. Jon opened by asking what the fleet is likely still
not realizing is ineffective ("the march of the 9s"). The assistant named five candidate failure
classes, then on a follow-up question retracted its own answer as itself an instance of the
overcorrection it was asked about — "the error taxonomy has become the work product." Jon required
co-trunk review of any Secretary claim going forward, at which point the assistant caught its own
in-flight procedural defect: it had sent a critical judgment about CFL's overnight work to Jon and
to Professional before sending anything to CFL itself ("criticism behind the back"), a mistake its
own rulings file had named as a rule an hour earlier. The session then produced a standing routing
doctrine (direct-to-trunk-plus-ledger-row vs. CC vs. through-Secretary, with four named triggers for
the latter) and a standing rule that a question mark from Jon is not a complaint signal. The back
half of the session traced a claimed "resident corrected a true finding into a false one" episode:
the resident's closing report said a Jacobian-teaching conversation "ends mid-baseline," which the
assistant confirmed was false by reading the primary packet directly (the conversation actually
ends mid-Phase-4). Jon then correctly diagnosed the cause the assistant had first gotten wrong twice
— not pipeline byte loss, but a stale zip export (the extracted corpus lagged the live claude.ai
conversation, so the resident read an early, shorter snapshot and mistook the artifact's end for the
conversation's end). The session closes with Jon reframing the whole episode as a memory/grounding
class ("we hadn't reached back far enough to have the grounding to fix it") and approving an
investigation lane bounded by `rulings/` as its denominator, then all four of the session's proposed
writes failing with "No approval received" once Jon stepped away.
