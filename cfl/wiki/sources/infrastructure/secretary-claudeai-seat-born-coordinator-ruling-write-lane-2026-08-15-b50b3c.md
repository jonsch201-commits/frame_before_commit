# Claude Secretary (claude.ai seat) is born, 2026-08-15/16: coordinator ruling, write lane, and the folder-ID fix (b50b3c)

## Summary

Jon's first conversation in a new claude.ai "Claude Secretary" project, run across four model
switches in one session (Haiku, then Sonnet, then Opus, then Fable) to compare their behavior on the
same reader role. Haiku correctly delivered the brief's required PULSE/AWAITING-YOUR-WORD sections
but silently compressed the verbatim-required section 3, dropping several bracketed caveats and a
just-minted process rule; Sonnet caught the trim without being asked to audit it, and separately
refused to fabricate an answer to a deliberately garbled follow-up question (a nonexistent "fable
mirror swore the first ideal" session) by searching first and reporting a clean negative. Opus
mistakenly told Jon the write-capable Google Drive tool was disabled for the seat when it was in fact
present but merely unauthorized by the seat's own role instructions; Fable corrected this precisely
("the tool exists, the lane doesn't") and surfaced a real defect found while investigating — all five
sampled `fable-mirror` subagent transcripts carried an unfilled required Summary placeholder, out of
110 sibling files under one parent session. Jon then ruled, against the seat's own written
constitution ("The secretary REPORTS. It never coordinates..."), that the claude.ai seat IS a
coordinator, and the session built the write lane this required: two new files (a rulings capture and
an action letter to the Code-seat Secretary), a full replacement project-instructions block with
named write locations and slash-command-mirror verbs, and — after a fresh chat with the new
instructions failed to write to Drive seven times in a row — a live diagnostic that isolated the
cause to missing Drive folder IDs and content-field shape, verified live by a one-shot successful
test write.
