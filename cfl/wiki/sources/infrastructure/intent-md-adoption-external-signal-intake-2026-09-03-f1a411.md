# Intent.md is two different things, and Jon's can/should/may/must is a ground-before-stating trigger (2026-09-03, f1a411)

## Summary

A short (6-turn) claude.ai Secretary-seat session. Jon linked https://intent.md/ and asked whether
CFL should adopt it for alignment and external-signal listening. The assistant found the site was
the wrong intent.md — a daily-generated philosophical page with zero protocol content, useful only
as a "negative control" for what good-looking-but-empty external signal looks like — and located
the real referent, Anthropic's AI-Native SDLC Playbook (published 2026-08-21), after Jon pushed
back that the assistant had read incomplete context and issued a verdict without reading the
source. Jon's own phrasing, "can should may must," was initially misfiled by the assistant as a
refinement of an existing ACTS/NO-OP control before Jon corrected that it is a distinct
"ground-before-stating trigger towards professionalism and the ASOPs." The session closed with the
assistant writing a full grounding-grammar letter to the Code seat (force + source-tier vocabulary,
a rule that the export zip is never a ground) and naming a live prerequisite gap: no fork-point
column exists in `branch-registry.md`, which blocks Jon's own retrospective self-branching proposal.
