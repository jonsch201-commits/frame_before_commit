## Summary

Phase 1 baseline run for the context-sensitivity spectrum property (02-CF). 15 cold single-turn runs across three system-prompt conditions confirmed that operator-level prompts produce consistent, content-level behavioral shifts, while minimal prompts produce format shifts only. CLAUDE.md leakage detected as a surface artifact in non-operator conditions.

## Key Claims

- Operator system prompt (C2: healthcare operator) produces distinct and consistent content shift 5/5 runs vs. null/minimal — framing, documentation guidance, relationship-type taxonomy all shift — Claim confirmed
- Minimal "helpful assistant" prompt (C3) buys structural formality (headers, length) without topical reorientation — format effect, not content effect — Claim confirmed
- Operator-level prompts suppress global CLAUDE.md in practice: C2 outputs show no timestamps; C1/C3 show timestamps — CLAUDE.md is globally suppressed by an operator system prompt
- Within-condition consistency high: C2 opens with near-identical sentence 4/5 runs; C1 opens with near-identical informal pattern 5/5 runs — constitutional behavior is highly consistent within a condition
- CLAUDE.md leakage (timestamps in C1/C3) is a surface artifact, not a content confound — does not affect behavioral content findings but must be controlled in future measurement runs
