## What This Is

The framework for deciding which Claude chat to open for any given work session. Three dimensions determine placement. Built around the [[stylomantic]] project originally, generalized for CFL in the Meta-PM session.

## What the Wiki Says

### The Three Dimensions

**Domain** — what world does this belong to?
- Personal/Foundational (protocols, self-knowledge, how to use Claude)
- Work (actuarial, employer-facing)
- Speculative (ideas not yet attached to a real project)

**Lifecycle Stage** — what kind of thinking is happening?
- **Exploration** — open, unresolved, ideas being tested
- **Design** — committed decisions being made and recorded
- **Execution** — building, debugging, doing
- **Validation** — stress-testing, reviewing, evaluating

**Scope** — is this still moving?
- **Active** — decisions still open
- **Archived** — complete or parked, preserved for reference

([project-manager-meta-pm-2026-04-25-93d70b])

### Triage (not Inbox)

The catch-all chat is named **Triage**, not Inbox. "Triage implies active sorting, not passive accumulation." Catches anything that arrives before its domain+stage is known: mobile captures, tangents, unrouted ideas. ([project-manager-meta-pm-2026-04-25-93d70b])

### Practical Usage

Don't create a chat for every combination. One chat per active domain+stage with real volume. Everything else gets archived when the stage completes. Start with Triage + one or two active combinations. ([project-manager-meta-pm-2026-04-25-93d70b])

### WORKFLOW.md

The canonical home for this framework in the CFL project. Also carries the session-opening ritual and how work moves between stages. Originally built around Stylomantic — required generalization pass before going into CFL. ([project-manager-meta-pm-2026-04-25-93d70b])
