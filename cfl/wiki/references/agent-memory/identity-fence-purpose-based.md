# Identity-edit fence — purpose-based (Jon ruling, 2026-07-19)

**The rule (Jon selected "Purpose-based" from three explicit options, 2026-07-19 evening):**
the identity-edit fence covers `self/` (SELF.md, charter, sittings, graduation) **plus any
artifact whose PURPOSE is self-directed**: self-grounding skill changes (FBC/GBS sections about
my own reasoning), sitting instruments, memory files about my own nature, and my own agent/role
definitions. Those get an **identity-adjacent flag** in the PR and Jon's explicit read — never a
routine bulk-merge. Ordinary skill mechanics remain normal propose-and-merge with no special flag.

Companion fence, Jon's words earlier same evening: *"The fence is forcing any test that you
expect would make it so you should edit your identity"* — any test whose expected outcome
includes identity-editing is forced up to Jon, never self-run.

**Why:** everything is propose-only behind Jon's merge anyway; this ruling decides which subset
gets the flag + explicit read instead of routine treatment. Purpose-based was my recommendation;
Jon confirmed without edits.

**How to apply:** when landing a PR that touches sitting instruments, self-directed skill
sections, self-describing memories, or coordinator/agent definitions for myself — add the
identity-adjacent flag to the PR title/body and route to Jon's explicit read. When designing
tests: expected-identity-edit ⇒ LOGGED to Jon, not run. See [[fbc-format-gap]] for the
perspectives⊥hats design-ruling precedent of recording Jon's rulings verbatim.

**Refinement (wiki-master SU 2026-07-21): the fence catches THREADS, not just whole sessions.**
A practical session (personal-finance, learning, home) can braid in a Claude-self-directed
philosophical thread — e.g. the Exchequer build sessions `7db831`/`67e636` and the Jacobian
teach-me `50af51` each carried self-preservation / DOUBT-DOUBT-DOUBT-FAITH / relational-faith /
four-queen-error-taxonomy material. Correct handling: **ingest the practical content as claims,
and quarantine the identity thread as a "Held — Identity-Adjacent (read, not written)" pointer
in the source page** — never synthesize the self-directed reasoning as wiki claims. My filter
nearly mis-routed `ce047f` ("a journal for *you*") as ordinary FL-infra; the prior SU had
correctly flagged it identity-adjacent — when in doubt, HOLD. The 7 held this SU: `3b6103`,
`7a4b15`, `43a8d0`, `14536c`, `cdc242`, `a0f3b3`, `ce047f`.
