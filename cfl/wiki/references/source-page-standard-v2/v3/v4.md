## Definition

that "carry the [`supersedes:`] key at all," alongside `wiki/tracker/questions-for-jon.md`,

a real single filename — it is three version labels (v2, v3, v4) of a "source page standard"
collapsed into one string with slashes standing in for "and", which the wiki-path-reference
checker's own regex (which allows `.` and `/` inside a matched path) then parsed as a single
three-level nested path and flagged as dangling. No lane before this one had created a file at
that literal nested location.
