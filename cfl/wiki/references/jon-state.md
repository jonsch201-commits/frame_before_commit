## Definition

[paraphrase] JON-STATE is the proposed name for a missing wiki surface holding Jon's own
schedule, budget, and intentions/expectations — one class of information a live Jon message can
carry that no standing wiki page captures. The proposal (FM-1, ticket text quoted below) frames it
as a derived, timestamped, superseding-rows page, refreshed by a boundary ritual run at every Jon
message, holding only his stated facts with primaries — explicitly NOT inference. Jon's own
question that motivated the ticket, quoted [verbatim] from FM-1's own citation of him: *"What
would you have missed if not for me sending this message? Is that a wiki defect or a skills
defect or a tools defect?"*
