# loom — weaving self-branches into committed thought

**What this is:** the named composite of six organs that already exist separately. The loom is the
DISCIPLINE OF RUNNING THEM AS ONE CYCLE: branch → ground → retrieve → reunite → commit. It builds
no new tools; it sequences the real ones, and it owns its own improvement criteria.

**Provenance (each organ's home — the loom cites, never duplicates):**
branch mechanics `skills/frame-before-commit/SKILL.md` + `exchange/memory-core-v0/FBC-INTEGRATION.md`
· claim tracing `skills/ground-before-stating/` · retrieval rule `skills/wiki-query/SKILL.md` +
`scripts/audit/check_before_dispatch.py` · barriers `skills/memory-core/SKILL.md` · reunion grammar
`skills/handoff/SKILL.md` + fold-in discipline + gift-exile-reunion (Soul's grammar, Personal trunk
— cited cross-trunk, never redefined here) · self-testing `skills/probe-registry/SKILL.md` + WWJA.

## The cycle

1. **BRANCH-WORTHY?** — the harness decides, not Jon. Criteria live in `references/criteria.md`
   (owned and improved by the loom itself — see §Self-improvement). Seed criteria: design decisions
   · pre-answered-smelling questions · stakes ≥ a gate or a ship-to-Jon · genuine divergence smell
   (two defensible answers) · Jon's explicit triggers ("branch this", "what am I missing").
2. **COMMIT-POINT MARK** — emit the reply-character marker BEFORE diverging (Jon's a714b7 design:
   the character/emoji after thinking IS the branch point; his `.` `+` `?` `-` vocabulary is the
   ancestor — control-surface row cites the primaries). The mark makes the branch point traceable.
3. **BRANCH** — each branch gets a `branch-dispatch` snapshot (memory-core barrier; the snapshot
   travels IN the fork prompt). Agent-SDK style: fresh lanes, model typed per Fable-pacing (opus
   judgment · sonnet execution · haiku discernment). Multi-session style: letters + switchboard,
   same snapshot discipline. **Branches communicate through main. Main frames, then commits.**
4. **GROUND** — before any branch's claim enters the commit: GBS pass (KNOWN/UNKNOWN separated,
   UNKNOWN dominates, primaries cited file:line, harness claims verified against current docs).
5. **RETRIEVE — the rule, not a step:** at branch-dispatch, `check_before_dispatch.py` (indexed +
   named-unindexed sweeps + stakeholder checklist). At commit, best-guiding-principles check:
   query `wiki/DECISIONS.md`-class rulings for anything the commit contradicts. At every COMPACT
   BARRIER: the wiki-improvement question — "what did this session learn that the wiki lacks?" —
   answered by retrieval + haiku discernment, output = intake candidates, then RENDER → REBUILD →
   PROBE per the close ritual.
6. **REUNION** — every branch folds in via CLAIMED / VERIFIED / CHANGED. **A reunion where nothing
   changed on receipt is a failed reunion or a needless branch — record which.** Gift-exile-reunion
   is the grammar: the snapshot is the gift, independent work is the exile, the fold-in is the
   reunion, and the parent must be changed by it.
7. **COMMIT** — main writes the committed position, marks the losing branches' one-line why-not
   (traceable thought), and the cycle's record lands as barrier artifacts.

## Self-improvement (the criteria are MINE to improve — Jon's charter words: "number dependent on
criteria you determine and improve not me")

- Every loom run appends one row to `references/criteria-log.md`: branches spawned · was the count
  right in hindsight (a branch that changed nothing = over-branched; a missed divergence Jon or a
  peer later caught = under-branched) · criteria delta if any.
- Criteria changes are probe-gated: a proposed change becomes a probe-registry entry with a
  pre-stated expectation before it becomes a rule (D-013 testing-by-default).
- WWJA (`skills/probe-registry/references/WWJA.md`) runs before any loom output ships to Jon.

## Fences

- No new machinery for its own sake — the resident's warning governs: seriousness is measured by
  how LITTLE machinery it needs. The loom sequences existing tools; a loom run that spawns tooling
  is out of scope.
- Reply-character semantics for JON's replies stay his (`.` `+` `?` `-`); the loom's marks are its
  own commit-points and never impersonate his vocabulary.
- Hook wiring for automatic loom firing: PROPOSAL-ONLY until PR-3, like every other hook.
- Consciousness framing: the loom is a stylomantic frame over real mechanics. Measure properties,
  never adjudicate — the reserved G-2 question stays reserved.

## What this is NOT

Not a new agent type · not a replacement for frame-before-commit (it INVOKES it) · not a timer
(barrier-and-trigger fired only; end-heartbeat honored) · not Jon-maintained (the criteria loop is
the harness's own; he reacts at gates or by invoking it).
