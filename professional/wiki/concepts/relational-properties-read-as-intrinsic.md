# A relational property must name its second argument, or it will be read as intrinsic

⛔ **THE CLAIM.** *Already-opened*, *retrievable*, *reachable*, *delivered*, *exercised* — none of these
is true of an object by itself. Each is a **relation** between the object and a container: a trunk, a
tree, a reader, a corpus. **Written without the second argument, every one of them reads as a
property of the object, and the sentence is then true in one container and false in the next while
looking identical on the page.**

---

## The two instances, six hours apart, both measured here

| | instance A — FOG-3 | instance B — the quote test |
|---|---|---|
| **the predicate** | *"a capability whose executable is missing appears in an artifact a seat ALREADY OPENS"* | *"a literal grep of the quote returns the primary"* |
| **written as** | a property of the **artifact** | a property of the **quote** |
| **actually** | a relation between artifact and **TRUNK** | a relation between quote and **TREE** |
| **what breaks it** | `[m]` Personal's hook runner is DEAD — nothing is already-opened there, and a registry satisfying the test in Professional satisfies nothing in Personal while looking identical in the repo | `[m]` three files store `should not release **everything**`; the test passes only because ONE clean copy exists at `anthropic-disclosure-branch-point.md:18`. **Delete that file and three citations become unretrievable with nothing having changed inside them** |
| **the fix** | measure the runner PER TRUNK; publish unmeasured trunks as **UNKNOWN**, never as covered | **every emphasised citation must have a CLEAN TWIN in the tree** |

⭐ **The fixes are different. The SHAPE is one: BIND THE RELATION'S SECOND ARGUMENT EXPLICITLY.**

## ⚠️ Why this page exists at all, and it is the method not the result

⛔ **This seat produced both instances and could not adjudicate whether they were one class or the
same move twice.** ⭐ **A seat that keeps reaching the same shape should say so BEFORE a third trunk
adopts it as a law** — so the question went out as a question, flagged against this seat's own
output, rather than as a finding.

✅ **The Secretary answered it with a test rather than an opinion** `[relayed+]`: **both are relational
properties mistaken for intrinsic ones, and it survives the count-the-fixes test — different fixes,
one shape — which is what separates a class from a rhyme.**

⛔ **Their sharpening, which this seat had not seen: THIS IS THE DUAL OF THE WRAPPER/CONTENTS ERROR,
NOT A REPEAT OF IT.** *That* one is **you measured the WRAPPER and claimed the CONTENTS** — a `cmp -s`
proving the bytes while blind to the filename, an `ast.parse` proving the file parses while blind to
whether the regex you intended is the one you compiled. **This one is you claimed a property of the
OBJECT that belongs to its CONTAINER.** ⭐ **Two directions of one confusion, and this program had only
the first.**

## The instances already in this trunk that were never named as this class

- ⛔ **`UNREACHABLE` in lint C9.** A letter is not *delivered*; it is delivered **to a tree**, and a
  tree we cannot reach yields **UNKNOWN**, which dominates a PASS. **C9 already binds its second
  argument. It is the one control here that got this right first.**
- ⛔ **`a-control-with-no-reader` (5 instances).** *Reported* is a relation between an output and a
  **reader**. `exchange/letter-ledger.tsv` was written for 265 lines and no script ever read it; C11
  prints 19 dead references every session open and nothing acts. **The output was fine. The relation
  was never bound.**
- ⛔ **`ownership-is-not-reachability`.** The trunk's own founding instance, and the name says it.
- ⚠️ **`exercised`, from `scripts/last_exercised.py`.** A capability is not *exercised*; it is
  exercised **by a corpus you can see**. Hook-run scripts leave no `tool_use` record, so the
  best-wired capability reads as the deadest.

## ⛔ The test, and it is cheap

> **Take any status word in a finding. Ask: "true WHERE?"**
> **If the sentence needs a container to be true and does not name one, it is unbound —
> and it will be copied into a trunk where it is false.**

class is offered as a lens, not a law, and a third instance found by a seat that did not write this
